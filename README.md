# 照片打印排版工具

一款功能强大的在线照片打印排版工具，帮助用户快速将照片排列到各种标准纸张尺寸上进行打印。

## 功能特点

### 📸 照片管理
- **拖拽上传**：支持点击上传或直接拖拽照片到上传区域
- **照片预览**：上传后可在侧边栏查看所有已上传照片的缩略图
- **照片排序**：支持拖拽调整照片排列顺序
- **照片旋转**：点击旋转按钮可顺时针旋转90度
- **批量删除**：可单独删除照片或一键清空全部照片

### 📐 灵活的尺寸设置
- **照片尺寸预设**：
  - 一寸照片 (25×35mm)
  - 二寸照片 (35×49mm)
  - 护照照片 (35×45mm)
  - 自定义尺寸

- **页面尺寸预设**：
  - A4 (210×297mm)
  - A3 (297×420mm)
  - A5 (148×210mm)
  - A6 (105×148mm)
  - Letter (216×279mm)
  - Legal (216×356mm)
  - 4×6英寸 (102×152mm)
  - 5×7英寸 (127×178mm)
  - 8×10英寸 (203×254mm)

### 🎯 智能排版
- **自动计算**：自动计算最佳行列数量
- **手动设置**：可手动设置每行和每列的照片数量
- **间距调整**：可独立调整水平和垂直间距
- **实际布局**：支持设置自定义打印区域（默认值为页面尺寸的一半）
- **右下角定位**：实际打印区域固定在页面右下角，符合打印习惯

### 🖨️ 打印功能
- **即时预览**：实时预览排版效果
- **精确打印**：打印时自动隐藏界面元素，只打印排版内容
- **自动适配**：修改任何参数后自动更新预览

## 使用方法

### 1. 上传照片
- 点击上传区域或直接拖拽照片到上传区域
- 支持一次性上传多张照片
- 上传后可在缩略图区域管理照片顺序

### 2. 设置照片尺寸
- 从预设尺寸中选择或选择"自定义尺寸"输入具体数值

### 3. 选择页面布局
- 从下拉菜单选择目标打印纸张尺寸
- 系统会自动计算可容纳的照片数量

### 4. 调整间距
- 根据需要调整照片之间的水平和垂直间距

### 5. 排版控制
- **自动计算**：系统自动计算最佳排版方案
- **手动设置**：手动输入每行的照片数量和每列的照片数量

### 6. 自定义实际布局（可选）
- 如果需要使用部分页面进行打印
- 切换到"自定义实际布局"并输入具体尺寸
- 默认值为当前页面尺寸的一半

### 7. 生成并打印
- 点击"生成排版"按钮（或上传照片后自动生成）
- 确认预览效果
- 点击"打印照片"按钮进行打印

## 技术说明

- **JavaScript**：交互逻辑

### 响应式设计

- 侧边栏可滚动查看

### 打印优化
- 使用mm单位确保打印精度
- 打印时自动隐藏控制界面
- 保持页面比例和尺寸

## 注意事项

1. **照片质量**：建议上传高分辨率照片以获得最佳打印效果
2. **浏览器兼容性**：推荐使用现代浏览器（Chrome、Firefox、Edge、Safari）
3. **打印设置**：打印时请确保选择"实际尺寸"或无缩放
4. **纸张方向**：根据照片排列方向选择合适的纸张方向
5. **照片裁剪**：使用`cover`模式填充，可能会有少量裁剪

## 常见问题

### Q: 为什么照片有空白区域？
A: 这是为了保持照片原始比例的正常现象。如需完全填满，可调整照片或使用裁剪功能。

### Q: 如何确保打印尺寸准确？
A: 在浏览器打印设置中选择"实际尺寸"，避免选择"适合页面"等缩放选项。

### Q: 可以一次处理多张照片吗？
A: 可以，支持一次性上传多张照片，系统会自动循环使用照片填充所有格子。

### Q: 照片旋转后会影响打印吗？
A: 不会，旋转会实时应用到预览和打印中。
